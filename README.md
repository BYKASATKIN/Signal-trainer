# СИГНАЛ — интерактивный тренажёр цифровой безопасности

Автор: Касаткин Даниил Андреевич, Костромской государственный университет, группа 26-ИСбо-3.

Конкурс «Передовая безопасность», номинация «Мы создаем продукты передовой безопасности в информационной сфере».

Сайт (после включения GitHub Pages): https://bykasatkin.github.io/Signal-trainer/

## Что делает проект
- Показывает 4 учебных ситуации: подозрительная подработка, призывы к насилию в закрытом чате, опасный контент и шантаж.
- Предлагает выбрать действие и сразу объясняет, какой выбор безопаснее.
- Выводит итоговый результат и позволяет начать снова.

Тренажёр сделан на HTML, CSS и JavaScript без сторонних зависимостей. Не требует аккаунта, не собирает ответы, не отправляет данные на сервер. Все ситуации вымышлены.

## Как включить публичную страницу
1. Откройте «Settings» репозитория → «Pages».
2. В разделе «Build and deployment» установите «Deploy from a branch».
3. Выберите branch «main», folder «/(root)» и нажмите «Save».
4. Дождитесь подтверждения публикации и проверьте адрес сайта на iPhone в Safari.

Работа предназначена для обучения, а не для установления причастности людей к преступлениям.
